辦學理念與班級簡介

我們秉持「音樂深耕、全人教育」的信念，專注於提供扎實的國樂專業指導，同時打造完善的學科輔導機制，讓學生在國樂天地盡情揮灑時，依然保有優秀寬廣的升學實力。

術科與學科的黃金平衡

國樂班不僅注重器樂演奏技巧、合奏默契與樂理視唱，更嚴格把關一般學科教學品質。專業老師與導師共同輔導，讓孩子學音樂不脫節、學業表現同樣耀眼。

藝術薰陶與自信塑造

透過大合奏的團隊合作與個人獨奏比賽，培養孩子沉著的抗壓性、專注力與表達自信。讓音樂成為一生相伴的心靈養分。

四大核心特色

提供最全面的學習資源與成長環境，幫助每一位熱愛音樂的學生綻放光芒。

頂尖師资團隊

聘請現任國家級國樂團知名演奏家、各大大學音樂系教授親自指導分組與個別課，傳承正統演奏心法。

專業場地與樂器

設有大型演奏合奏室、獨立分組琴房，並備有完善的高階大型打擊樂器與特殊樂器，提供無憂練琴環境。

多元展演舞台

定期舉辦年度成果發表會、參與全國音樂大賽、社區巡演與跨校交流演練，累積豐富舞台實戰經驗。

雙軌升學輔導

專人規劃音樂術科升學檔案與一般學科複習進度，輔導畢業生順利考取各大學音樂系或優質普通高中/大學。

國樂四大聲部介紹

吹、拉、彈、打四大聲部交織出層次豐富的東方樂章，點擊切換了解各聲部樂器魅力。

Wind Instruments

吹管組 ‧ 清亮高亢

吹管樂器是樂團主旋律與情感色彩的重要來源。包含高亢明亮的竹笛、具備和聲效果的笙，以及穿透力極強的嗩吶等。

梆笛 / 曲笛 笙 (鍵笙) 嗩吶 簫
Plucked String Instruments

彈撥組 ‧ 點滴點線

彈撥樂器賦予國樂獨一無二的點狀音色與打擊質感。琵琶的華麗、阮咸的溫潤、古箏的仙氣與揚琴的和聲，交織成綿密的聲響網。

琵琶 柳琴 中阮 / 大阮 揚琴 / 古箏
Bowed String Instruments

拉弦組 ‧ 情感如歌

弓弦樂器如歌般的線條是樂團抒情基調。二胡宛如人聲的婉轉、高胡的明亮，搭配革胡與低音革胡的渾厚低音，構成飽滿聲部。

高胡 / 二胡 中胡 革胡 (大提琴) 低音革胡 (低音提琴)
Percussion Instruments

打擊組 ‧ 震憾靈魂

節奏與氣氛的掌控心臟。融合東方傳統排鼓、大鑼、鈸與西洋定音鼓、木琴等，為樂曲注入強大的張力與氣勢。

中國排鼓 / 堂鼓 大鼓 / 鑼鈸 西洋定音鼓 馬林巴木琴
